# ChooseYourDish - Project Instructions

This project is an Android application built with Jetpack Compose, Material 3, and modern Android architecture components.

## Tech Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose with Material 3
- **Dependency Injection:** Hilt
- **Networking:** Ktor
- **Database:** Room
- **Image Loading:** Coil
- **Animations:** Lottie
- **Build System:** Gradle (Kotlin DSL)

## Development Mandates

### Jetpack Compose & UI
- **Edge-to-Edge:** Always call `enableEdgeToEdge()` in `onCreate` before `setContent`.
- **System Bars:** Use `Scaffold` and `innerPadding` to handle insets. Avoid hardcoded padding for status/navigation bars.
- **Material 3:** Prefer Material 3 components and color schemes.
- **State Management:** Use `rememberSaveable` for simple state and `ViewModel` with `StateFlow` for complex logic. Host state whenever possible.

### Architecture & DI
- **Hilt:** All ViewModels and Repositories should be injected using Hilt. Use `@HiltViewModel` and `@AndroidEntryPoint`.
- **Layers:** Maintain clear separation between `data`, `domain`, and `feature` modules.

### Testing Strategy
- **Unit Tests:** Use JUnit 4 and MockK. Focus on business logic in ViewModels and Repositories.
- **UI Tests:** Use Compose Testing APIs. Put UI tests in the `test` source set and run with Robolectric when possible for speed.
- **Screenshot Tests:** Use Compose Preview Screenshot Testing for component-level verification.

### Build & Maintenance
- **AGP Upgrade:** Follow the AGP 9 migration guide for any build system updates.
- **R8/ProGuard:** Ensure R8 rules are updated for any new library integration.
