# ChooseYourDish - Project Context & Index

This project is an Android application built with Jetpack Compose, Material 3, and modern Android architecture components.

## Tech Stack & Architecture Map
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose with Material 3
- **Dependency Injection:** Hilt (Using standard MVVM / Clean Architecture boundaries)
- **Networking:** Ktor
- **Database:** Room
- **Image Loading:** Coil
- **Animations:** Lottie
- **Build System:** Gradle (Kotlin DSL) with Version Catalogs
